Data Source Search, trending, video info, and channel pages are all loaded from the Ludus server. If it's unavailable, the official YouTube Data API (then public backup servers) takes over for search, trending and channels; video info and recommendations only use the API when you click to load them, to save quota. If a video won't play, try another server from the player's server menu.
